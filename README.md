# port_monitoring
Oz serveriniz daxilinde aciq portlari,pid,servislerini gormek ucun sade port monitoring tool. Python


1-1. Server daxilində fayl yaradın:

```bash
nano port_monitor.py
```

2. İcra icazəsi verin:

```bash
chmod +x port_monitor.py
```

3. Canlı olaraq terminalda işlədin:

```bash
sudo python3 port_monitor.py
```
